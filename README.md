# TownyArchitecture (v1.1.0)

Плагин для серверов Minecraft (Paper 1.20+) с поддержкой **Towny Advanced** (0.98+) и **mcMMO** (2.1+).  
Позволяет городам возводить монументальные архитектурные сооружения и Чудеса Света на выделенных строительных чанках, наделяя жителей постоянными пассивными баффами и эффектами.

---

## 🏛 Основные возможности

1. **Чанковая система размещения проектов**:
   - Постройки занимают зоны `1x1`, `1x2` / `2x1` или `2x2` (Чудеса Света) чанков.
   - Мэр или помощник города выделяет чанки командой `/plot set build` (или `/builds plot set build`).
   - Автоматический алгоритм сканирования определяет доступные смежные строительные чанки в обеих ориентациях.

2. **Интеграция с mcMMO (Строгая проверка навыка)**:
   - Проверяется исключительно навык строительства (`BUILDING` по умолчанию).
   - Пустые аккаунты с 0 уровнем не могут возводить постройки без прокачки.
   - За каждый установленный блок проекта строителю начисляется опыт mcMMO.

3. **Городские баффы и зоны действия**:
   - **Строго для граждан**: баффы получают исключительно жители города, владеющего зданием.
   - `1x1 чанк`: радиус 5 чанков вокруг постройки.
   - `1x2 / 2x1 чанка`: вся заявленная территория города Towny.
   - `2x2 чанка (Чудеса Света)`: глобально во всех мирах для граждан города (1 Чудо Света на весь сервер!).
   - **Порог прочности (70%)**: при повреждении здания в ходе осад/взрывов баффы автоматически отключаются до ремонта.

4. **Интерактивный HUD и Меню**:
   - **Красивое GUI `/builds` (54 слота)**: интерактивные карточки чертежей, профиль строителя, статистика города, инструкция и свечение доступных проектов.
   - **Живой BossBar и Action Bar**: отображение названия, прогресса (в %), состояния (Готово / Повреждено / В процессе) и оставшихся ресурсов.
   - **Физический ремонт**: восстановление прочности происходит путем ручной установки недостающих блоков чертежа.

## 📋 Команды и Права

### Команды:
| Команда | Описание |
| :--- | :--- |
| `/builds` | Открыть главное меню чертежей и проектов |
| `/plot set build` | Назначить / снять строительный статус с текущего чанка |
| `/builds plot list` | Просмотреть список строительных чанков города |
| `/builds info` | Статус, прочность и необходимые материалы здания на текущем чанке |
| `/builds repair` | Инструкция и список блоков для восстановления постройки |
| `/builds wonder reset <id>` | *(Админ)* Сбросить статус воздвигнутого Чуда Света |

### Права (Permissions):
| Право | Описание | По умолчанию |
| :--- | :--- | :--- |
| `townyarchitecture.use` | Доступ к командам просмотра чертежей и статуса | `true` (все игроки) |
| `townyarchitecture.builder` | Право возводить блоки на строительных участках | `op` / ранг `builder` в Towny |
| `townyarchitecture.admin` | Административные команды плагина | `op` |

## ⚙ Конфигурационные файлы

- `config.yml` — основные настройки, параметры баффов, интервалы и сообщения.
- `buildings.yml` — база чертежей зданий (габариты, иконки, материалы, баффы).
- `data.yml` — сохранение активных построек, выделенных участков и Чудес Света.

## 📦 Готовый плагин (JAR)

Скомпилированный файл: **[dist/TownyArchitecture-1.1.0.jar](dist/TownyArchitecture-1.1.0.jar)**

Положите JAR в папку `plugins/` сервера Paper 1.20+.

---

## 🛠 Сборка проекта

Сборка осуществляется с помощью Maven:
```bash
mvn clean package
```
Готовый JAR-файл будет создан в папке `target/TownyArchitecture-1.1.0.jar` (копия публикуется в `dist/`).
